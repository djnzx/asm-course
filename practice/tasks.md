Нижче — набір із **15 практичних робіт** з **Assembler i386 (NASM) під Debian Linux** з **I/O через `int 80h`**, ранжованих **від простих до складних**. Кожна робота має: **вхід**, **вихід**, **що використати**, **критерії** + **персоналізацію**, щоб зменшити копіювання.

---

## Персоналізація (використовується в усіх задачах)

Нехай студент обчислює параметри зі своїх даних:

* `Y3` — **третя цифра року народження** (наприклад 2004 → `0`)
* `Y4` — **четверта цифра року народження** (2004 → `4`)
* `D` — **день народження** (1..31)
* `M` — **місяць народження** (1..12)
* `N` — **порядковий номер літери "n"** у прізвищі (1..довжина; якщо літери `n` немає — взяти `N = 3`)

Рекомендовані похідні значення (щоб у всіх задачах були різні числа):

* `A = 10 + D`
* `B = 20 + M`
* `K = 1 + (Y3 + Y4) mod 9`  (дає 1..9)
* `S = D + 10*M + 100*Y4`  (індивідуальне “зерно”)

> У коді ці значення можна або вводити з консолі, або “зашити” як константи, але **краще вводити**, щоб перевірка була чесною.

---

## Загальні критерії до коду (для всіх 15)

* **NASM i386**, секції `.data/.bss/.text`, точка входу `_start`.
* Ввід/вивід **лише через `int 0x80`**: мінімум `sys_read(3)`, `sys_write(4)`, `sys_exit(1)`.
* Повинні бути власні підпрограми (мінімум 2) з викликом через `call/ret`.
* Коментарі **лише про базові блоки**: `; I/O`, `; parse`, `; math`, `; loops`, `; logic`, `; memory` тощо. **Без “згенеровано ChatGPT”**.
* Код компілюється і лінкується:

  * `nasm -f elf32 -g -F dwarf main.asm -o main.o`
  * `ld -m elf_i386 -o main main.o`
* У репозиторій: папка `01` … `15`, у кожній:

  * `main.asm`
  * `README.md` (коротко: як зібрати/запустити, приклад вводу-виводу)
  * `screenshot.png` (компіляція + запуск + результат)

# Практична 01. Ввід числа і базові операції з регістрами та пам’яттю

**Мета:** навчитися читати рядок, перетворювати на число, зберігати в пам’яті.

**Вхід:** одне ціле число `x` (0..1_000_000).
**Вихід:** надрукувати:

1. `x`
2. `x + A`
3. `x - B`

**Використати:**

* `sys_read` в буфер (мін 32 байти)
* власний `atoi` (рядок → int) і `itoa` (int → рядок)
* збереження `x` у змінній в `.bss` (операції з пам’яттю)

**Персоналізація:** `A = 10 + D`, `B = 20 + M`.

---

# Практична 02. Сума цифр і робота з діленням (unsigned)

**Мета:** `div`, залишок, цикл.

**Вхід:** одне **додатне** число `x` (1..2_000_000_000).
**Вихід:**

* сума цифр `sumDigits(x)`
* кількість цифр `len(x)`

**Використати:**

* `div` (unsigned), `edx:eax / r32`
* цикл `while x > 0`
* обнулення `edx` перед `div`

**Персоналізація:** додатково вивести `sumDigits(x) + K`.

---

# Практична 03. Signed vs Unsigned: порівняння і гілкування

**Мета:** відрізняти `jl/jg` від `jb/ja`.

**Вхід:** два 32-бітні числа `a` і `b` (дозволити від’ємні).
**Вихід:** 4 рядки:

1. результат порівняння `a` і `b` як **signed** (`a < b`, `=`, `>`)
2. результат порівняння `a` і `b` як **unsigned**
3. `max_signed(a,b)`
4. `max_unsigned(a,b)`

**Використати:**

* умовні переходи `jl/jg/je` і `jb/ja/je`
* акуратне виведення тексту (“SIGNED: a < b”…)

**Персоналізація:** у тестах обов’язково включити значення на межі, наприклад `a = S`, `b = -S`.

---

# Практична 04. Масив у пам’яті: заповнення і пошук мін/макс

**Мета:** індексація, базові цикли, робота з `.bss`.

**Вхід:** `n` (5..50).
**Вихід:**

* масив `n` чисел (вивести в один рядок)
* `min`, `max`, їх індекси

**Використати:**

* виділити масив `dd 50 dup(?)` у `.bss`
* заповнити значеннями за формулою: `arr[i] = (S + i*K) mod 1000`
* цикл `for` по індексах

**Персоналізація:** формула використовує `S` і `K`.

---

# Практична 05. Пошук даних: лінійний пошук + підрахунок входжень

**Мета:** пошук по масиву, підрахунок.

**Вхід:** `n` (10..100), потім `n` чисел, потім `target`.
**Вихід:**

* перший індекс `target` або `-1`
* кількість входжень
* список усіх індексів (через пробіл)

**Використати:**

* масив у `.bss`
* лінійний пошук
* форматований друк списку індексів

**Персоналізація:** `target = (D*100 + M*10 + Y4)` якщо студент не вводить `target` (опція: дозволити “авто-target”).

---

# Практична 06. Генерація “рандому” (LCG) і гістограма

**Мета:** псевдорандом, модуль, лічильники.

**Вхід:** `n` (100..1000).
**Вихід:**

* згенерувати `n` чисел у діапазоні 0..9
* надрукувати гістограму частот (10 рядків):
  `0: ##### (count)` … `9: ### (count)`

**Використати:**

* LCG: `x = (1103515245*x + 12345) mod 2^31`
* `x % 10`
* масив частот `freq[10]`

**Персоналізація:** `seed = S + N`.

---

# Практична 07. Бітові операції: маски, зсуви, підрахунок бітів

**Мета:** `and/or/xor/not`, `shl/shr`, bit count.

**Вхід:** одне 32-бітне число `x`.
**Вихід:**

* `x` у двійковому вигляді (32 біти, групи по 4)
* кількість одиничних бітів (popcount)
* `x` після операцій:

  * встановити біти на позиціях `p` і `q`
  * очистити біт на позиції `r`

**Використати:**

* маски `1 << p`
* цикл 32 рази для друку бітів
* popcount через `shr` + `and 1` (базово)

**Персоналізація:**
`p = (D mod 16)`, `q = (M mod 16)`, `r = (Y4 mod 16)`.

---

# Практична 08. Вкладені цикли: “ялинка” (форматований друк)

**Мета:** вкладені цикли, пробіли/символи, акуратний вивід.

**Вхід:** висота `h` (5..25).
**Вихід:** символьна ялинка з `*`:

```
    *
   ***
  *****
 ...
```

**Використати:**

* два вкладені цикли: пробіли + зірочки
* `sys_write` малими блоками або через буфер-рядок

**Персоналізація:** `h = 5 + (D mod 10)` (якщо не вводять вручну).

---

# Практична 09. “Конверт/рамка” + діагоналі

**Мета:** умовні переходи всередині подвійного циклу.

**Вхід:** `w` (10..60), `h` (5..30).
**Вихід:** прямокутник, де:

* рамка `#`
* діагоналі `X`
* порожнє поле `.`
* у кутах `@`

**Використати:**

* подвійний цикл по `y` і `x`
* умови: `x==0 || x==w-1 || y==0 || y==h-1`, `x==y`, `x==w-1-y`
* запис у буфер рядка і один `write` на рядок

**Персоналізація:** `w += (Y4 mod 5)`, `h += (M mod 3)`.

---

# Практична 10. Рядки в пам’яті: пошук підрядка

**Мета:** робота з рядками, пошук, індекси.

**Вхід:** два рядки: `text` (до 200), `pattern` (до 50).
**Вихід:**

* перша позиція входження або `-1`
* кількість входжень (перекриття дозволити або заборонити — вказати в README)

**Використати:**

* буфери в `.bss`
* власна функція `strlen`
* пошук “наївним” алгоритмом (дві вкладені перевірки)

**Персоналізація:** якщо `pattern` порожній — зробити `pattern` з 2 символів, що залежать від `N` (наприклад, літера з ASCII `65 + (N mod 26)` двічі).

---

# Практична 11. Робота з пам’яттю: реверс масиву + копіювання блоків

**Мета:** `movs*` або ручне копіювання, індексація.

**Вхід:** `n` (5..200), `n` чисел.
**Вихід:**

* вихідний масив
* розвернутий масив
* перевірка: чи є масив паліндромом

**Використати:**

* додатковий буфер для копії
* копіювання блоку (дозволити `rep movsd` як бонус, але базово можна циклом)
* порівняння пар елементів

**Персоналізація:** додати ще перевірку “паліндром після XOR з K”.

---

# Практична 12. Сортування (пошук даних + вкладені цикли)

**Мета:** вкладені цикли, обміни, адресація.

**Вхід:** `n` (10..100), `n` чисел.
**Вихід:**

* масив до сортування
* масив після сортування (за зростанням)
* медіана (для парного `n` — нижня або середнє; чітко зафіксувати)

**Використати:**

* bubble sort або selection sort
* обмін двох `dd` у пам’яті
* уважний індексний доступ `[base + idx*4]`

**Персоналізація:** частину елементів генерувати автоматично через LCG із `seed = S`, якщо студент хоче (опціонально).

---

# Практична 13. Рекурсія: факторіал / Фібоначчі з обмеженням

**Мета:** стек, `call/ret`, збереження регістрів.

**Вхід:** `n` (0..12 для factorial, 0..40 для fibonacci).
**Вихід:**

* `fact(n)` або `fib(n)`
* кількість рекурсивних викликів (лічильник)

**Використати:**

* рекурсивна функція з прологом/епілогом
* домовленість про передачу аргументів (наприклад через `eax`) і повернення в `eax`
* збереження `ebx/esi/edi` якщо використовуються

**Персоналізація:** `n = (D + M + Y4) mod 12` (якщо студент не вводить).

---

# Практична 14. Виклик коду на C: `printf` або власна C-функція

**Мета:** лінкування NASM + GCC, ABI (cdecl), стек.

**Вхід:** `x`, `y` (цілі).
**Вихід:**

* результат обчислення на C-функції, викликаної з ASM
* те саме обчислення, але виконане в ASM (для звірки)

**Використати:**

* C-файл `helper.c` з функцією, наприклад:

  * `int mix(int x, int y, int k) { return (x*x + y*y + k) % 10007; }`
* Виклик з ASM за cdecl: push args справа-наліво, `call`, `add esp, ...`
* Лінкування через `gcc -m32` (або `ld` з потрібними CRT, але простіше — gcc)

**Персоналізація:** `k = K`.

**Збірка (приклад для README):**

* `nasm -f elf32 main.asm -o main.o`
* `gcc -m32 -no-pie -o main main.o helper.c`

# Практична 15. Міні-проєкт: “калькулятор рядка” + C для форматування

**Мета:** інтегрувати все: парсинг, масив/рядки, цикли, умовні, бітові, рекурсія/функції, C-виклик.

**Вхід:** один рядок виразу у форматі:
`<int> <op> <int>`
де `<op>` один з: `+ - * / % & | ^ << >>`
(пробіли обов’язкові)

**Вихід:**

* надрукувати вираз у нормалізованому форматі (через C-функцію форматування)
* результат (в ASM)
* додатково: для `<<` і `>>` — показати результат ще й у двійковому вигляді (як у практичній 07)

**Використати:**

* парсинг 2 чисел + оператора зі строки
* таблиця переходів по оператору (ланцюжок порівнянь або jump-table)
* перевірка ділення на нуль і коректна помилка
* C-функція `format_expr(char* out, int out_sz, int a, const char* op, int b, int res)` з `snprintf`

**Персоналізація:** якщо оператор `*`, то додатково домножити результат на `K` (і це описати в умові).
